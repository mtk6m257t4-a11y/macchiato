# Macchiato

Macchiato is a small macOS menu bar app with a cup button for toggling sleep prevention. Steam on the cup means system sleep is disabled. Its optional **Keep Display Awake Too** setting runs macOS `caffeinate -d` as a user launch job.

The app uses `pmset -a disablesleep 1` to keep the Mac awake, including when the lid is closed. A root-owned, one-shot `launchd` job reapplies that setting after a restart. The setting also remains in effect if the menu app quits or crashes. Macchiato does not disable the macOS lock screen. Closed-lid behavior has not been verified on every Mac model.

## Download and use

Download `Macchiato.zip` from the [latest release](../../releases/latest), unzip it, and open `Macchiato.app`. Click the cup to turn sleep prevention on or off. The first use asks for administrator approval to install `MacchiatoHelper` and a narrow permission rule for future on/off clicks. Right-click the cup to change the display option, remove that permission, or quit while leaving the current state in place.

The installed helper is `/Library/PrivilegedHelperTools/MacchiatoHelper`. Its startup and display jobs use `local.codex.macchiato` labels. The helper runs only for a toggle or at startup; the display job runs continuously only when its option is on. Keeping a Mac awake uses more battery than sleep.

## Build from source

On an Apple silicon Mac with macOS 13 or newer, Xcode Command Line Tools, and Python 3:

```sh
/bin/zsh scripts/build.sh
```

The signed app and ZIP are created in `dist/`. The app and helper use ad hoc signatures, so macOS may require you to approve opening a locally built copy. No third-party packages are required.

If the selected Swift compiler and default macOS SDK do not match, set `MACCHIATO_SDK` to a compatible installed SDK before running the build script.

The menu app is in `src/Macchiato.swift`, the privileged helper is in `src/MacchiatoHelper.c`, and the icon is generated by `src/render_app_icon.swift`. `scripts/build.sh` assembles the app bundle.

## Removing the installed helper

Use **Remove One-Click Permission…** in the app's right-click menu. That restores normal sleep and unregisters Macchiato's jobs. If the app has already been removed, reinstall it and use that menu action. Manual steps are in the [usage guide](docs/USAGE.md).
